# === Recommended production upgrade path ===
# The build environment that generated this code had no network access,
# so it couldn't install the spec's recommended stack. The code is
# structured so each of these is a drop-in swap:
#
#   fastapi + uvicorn[standard]      -> replaces Flask (routes/*.py would
#                                        become APIRouter files; same logic)
#   sqlalchemy + psycopg2-binary     -> replaces db.py's raw sqlite3 layer,
#                                        pointed at PostgreSQL
#   alembic                         -> schema migrations instead of schema.sql
#   argon2-cffi                      -> replaces utils/security.py's scrypt
#                                        calls with argon2.PasswordHasher
#   python-dotenv                    -> load .env files locally
#   gunicorn                         -> production WSGI server
#
# pip install fastapi uvicorn[standard] sqlalchemy psycopg2-binary alembic argon2-cffi python-dotenv gunicorn
