# MessDesk UI Upgrade

The functional React/Vite application has been visually redesigned around a modern food/mess-management identity.

## What changed
- Food-first visual language: kitchen green, warm cream, fresh emerald accents.
- Animated floating food motifs and subtle background motion.
- New dashboard hero with clear primary actions.
- More polished statistic cards with visual hierarchy.
- Modern desktop sidebar and compact mobile bottom navigation.
- Redesigned login and registration experiences.
- Softer forms, rounded controls, improved focus states and hover motion.
- Responsive tables and layouts retained for the existing routes.
- Existing API calls, authentication flow and business logic were preserved.

## Reference direction
The motion direction is inspired by the supplied New York Philharmonic reference: large visual storytelling, layered composition and gentle movement. The implementation is original and adapted to a food/mess product rather than copying the reference site.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

If you already have dependencies installed, run:

```bash
npm run dev
```

The backend remains unchanged.
